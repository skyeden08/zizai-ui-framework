# 第三階段第 10 項｜三區獨立垂直捲動與 2:4:4 初始寬度比例

公開測試頁：
https://skyeden08.github.io/zizai-ui-framework/tests/region-independent-scroll/

## 使用者定案與實作

- 三區初始版面採 CSS Grid `grid-template-columns: 2fr 4fr 4fr`，左、中、右區依 2:4:4 比例分配寬度。
- 2:4:4 是初始預設比例，不代表固定寬度；三區仍可經第 9 項既有寬度請求機制調整。
- 拖曳時沿用各區既有 `requestSpace` 單向請求，由容器改寫自身的 Grid 軌道；未新增第二套協調機制。
- 收合仍沿用既有 `requestRegionState`；第 9 項介面及 `bindOpenClose`、`bindDragAdjustment` 能力職責不變。
- 未提出寬度請求的區域保留 2fr、4fr、4fr 預設彈性軌道；已提出寬度請求的區域依請求值設定軌道寬度。
- 容器只調整自身 `grid-template-columns`，不操作任何區域內部呈現、內容或操作。
- 左、中、右區各自保有獨立的垂直內容捲動視窗與捲動位置。

## 測試涵蓋

測試頁會在瀏覽器中執行下列檢查：

1. 左、中、右區各自具有可垂直捲動的內容視窗。
2. 分別捲動任一區時，另外兩區的捲動位置不變。
3. 三區可同時保有不同的捲動位置；依各區實際可捲動範圍設定比例，不假設三區最大捲動距離相同。
4. 初始版面依 2:4:4 比例分配三區寬度。
5. 左、右區送出既有寬度請求後，容器改寫 Grid 軌道，中間區取得剩餘可用寬度。
6. 中間區也可透過第 9 項既有寬度請求調整自身 Grid 軌道。
7. 中間區內部操作由中間區自身處理，不觸發容器協調請求。
8. 容器調整 Grid 軌道前後，中間區內部節點保持不變。
9. 三區仍沿用第 9 項既有開合、拖曳能力及單向介面；容器只調整自身 Grid 軌道，沒有新增 JS 空間量測公式，也沒有操作區域內部。

## 瀏覽器實測與驗收

請在 GitHub Pages 公開頁確認測試結果全部通過，並實際以滑鼠滾輪操作左、中、右區，確認捲動互不影響；再操作中間區內部控制，確認其操作自主。測試頁的自動檢查不取代使用者的實際操作驗收。
