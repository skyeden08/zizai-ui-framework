# 第二階段第 7 項：能力組合干擾測試

## 範圍

只對既有四項能力執行組合測試，不新增能力、不改變能力職責：

- 共用外觀（A）
- 開合（OC）
- 下拉選單（DD）
- 拖曳調整（DA）

## 測試矩陣

| 類型 | 組合 |
|---|---|
| 兩兩組合 | A+OC、A+DD、A+DA、OC+DD、OC+DA、DD+DA |
| 三項組合 | A+OC+DD、A+OC+DA、A+DD+DA、OC+DD+DA |
| 四項同時組合 | A+OC+DD+DA |

共 11 種組合。每種組合各自建立獨立測試情境，逐組顯示結果。

## 每組檢查項目

- 狀態：各使用位置自行持有狀態，互動不污染其他能力狀態。
- 樣式：組合使用時 CSS Variables 正常套用；不含共用外觀的組合標示不適用。
- 事件：click 與 pointer 事件留在各自能力及使用位置的連接範圍。
- 內容：能力只透過使用位置回呼工作，不改寫其他能力或使用位置內容。
- 生命週期：各能力可獨立解除連接；解除後不再呼叫原回呼。

測試失敗會在該組合下顯示檢查分類及連接處，便於定位。

## 執行

直接以瀏覽器開啟 GitHub Pages：

https://skyeden08.github.io/zizai-ui-framework/tests/capability-combinations/

本頁直接載入既有能力檔案，不依賴平台啟動入口。測試結果由 `test-runner.js` 動態產生。

## 注意

- 本測試使用合成 Pointer Events；為了可重現測試，僅在測試頁替拖曳把手提供 `setPointerCapture` stub。這不能取代使用者實際拖曳操作的瀏覽器驗證。
- 靜態檢查只能確認測試結構及依賴；是否通過必須以瀏覽器實際執行結果判定。
- 本頁是第二階段第 7 項組合測試，不代表第二階段整體驗收完成。
