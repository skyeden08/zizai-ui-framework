# 版面容器獨立測試

此測試只驗證第三階段第 1 項「建立版面容器」的最小容器邊界，不建立上方、左側、中間或右側區域，也不提前實作後續階段的版面協調行為。

## 瀏覽器測試

部署後以 GitHub Pages 開啟：

`/tests/layout-container/`

頁面會執行以下檢查：

1. 容器可註冊並建立 Shadow DOM。
2. 容器保留使用位置提供的內容與節點。
3. 區域內部操作仍由使用位置自行處理。
4. 容器未接管區域內容狀態或操作狀態。
5. 容器移除後重新掛載不重建或改寫內部內容。

本測試檔案已建立；瀏覽器實測須以 GitHub Pages 公開網址實際開啟後記錄，不以靜態檢查代替。
